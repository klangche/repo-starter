# changes

One small file per change. Copy `_TEMPLATE.md`, rename it to something unique (for example `add-install-check.md`) and fill it in.

- `type`: Added, Changed, Deprecated, Removed, Fixed or Security
- `bump`: patch, minor or major (you never write a version number)
- `feature`: optional, only for new user-visible features
- Below the second `---`: one sentence in English

The release step collects these files into VERSIONS.md and README.md and deletes them.
